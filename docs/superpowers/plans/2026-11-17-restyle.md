# Restyle (Tekt look) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle all six pages to match tekt.com.au's look (full-screen hero, outlined "blueprint" boxes with corner dots, ruled rows, square edges) using Pon Di Gas brand colors, Rajdhani display type and green buttons.

**Architecture:** One stylesheet (`assets/css/style.css`) rewritten around design tokens and a reusable `.box` component. The six HTML pages get a new header/footer/fixed-button block. `render.js` output changes from rounded cards to ruled rows and boxed cells, test-first. One small JS addition toggles a scrolled state on the header.

**Tech Stack:** HTML, CSS, vanilla JS (ES modules), existing Python check script. No new dependencies or font files.

**Spec:** `docs/superpowers/specs/2026-11-17-restyle-design.md`

## Global Constraints

- Static site, no build step, no new JS libraries, no animation libraries; keep root-absolute paths (`/assets/...`).
- Rajdhani SemiBold (600) and Bold (700) only, from `assets/fonts/` (already `@font-face`d), for h1-h4, nav, buttons, labels, dates. Body text: system UI font stack. No new font files.
- Tokens: page `#ECF1F4`; text and 1px lines `#111111`; text on photos `#ECF1F4`; buttons brand green `#009B3A` with white text in Rajdhani SemiBold at >= 19px; gold `#FED100` only on dark areas; lion red `#D80530` rare highlights; footer `#111111`.
- Square corners (`border-radius: 0`) and no shadows everywhere.
- Do not copy Tekt's text, images or fonts.
- Text contrast WCAG AA (4.5:1 body, 3:1 large text >= 24px or >= 18.66px bold).
- Header: fixed, transparent over hero, outlined boxes with corner dots; scrolled state gets a pale fill and the light logo variant. Hero is `100svh`; emblem removed from hero.
- Fixed bottom-left green button "Follow us on Instagram" linking to `https://www.instagram.com/evido__`.
- Mobile-first behavior at 375px with no horizontal scroll; `python3 -I scripts/check.py` and `render.test.html` (ALL PASS) stay green.

## Review Focus

- Header text over the bright photo: `assets/photos/hero.jpg` has a blown-out white sky across its top third, so light header text and light-outlined boxes can vanish. The hero overlay must darken the top as well as the bottom; verify header legibility by screenshot at desktop and 375px.
- Long values: a venue or event name of 40+ characters (e.g. "Nürburgring Nordschleife Grand Prix Circuit") wraps inside a row at 320px without overflow or overlap.
- Missing optional fields (no time, no position, no photo) leave no empty gaps, separators like " · " or the text "undefined".
- Empty states ("No upcoming races.", "No results yet.", "Sponsors coming soon.") look intentional inside the new layout, not like a broken box.
- No-JS or failed-JS: the nav is still reachable (menu not permanently hidden) and the header is legible on pages without a hero.
- Keyboard focus is visible on every outlined box/link, and the green button's focus ring is distinguishable.

## File Structure

- `assets/css/style.css`: tokens, base type, `.box`, header, hero, sections, rows, cells, footer, fixed button, responsive rules.
- `assets/js/render.js`: row/cell markup (changed).
- `assets/js/render.test.html`: tests for new markup.
- `assets/js/main.js`: adds scrolled-state toggle (existing data rendering and menu toggle stay).
- `index.html`, `results/`, `schedule/`, `sponsors/`, `team/`, `contact/` (each `index.html`): new header, footer, fixed button, section layout.
