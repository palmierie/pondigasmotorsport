# Pondigas Motorsport Team Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static, photo-led racing team site (results, schedule, sponsors) deployable on GitHub Pages at a custom domain.

**Architecture:** Plain HTML pages sharing one stylesheet. A small vanilla-JS module fetches JSON data files and renders results, schedule, sponsors and the home-page highlights. No build step. A Python check script validates data files and local links.

**Tech Stack:** HTML, CSS, vanilla JS (ES modules), JSON, Python 3 (check script only, stdlib), GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-17-team-site-design.md`

## Global Constraints

- No backend, CMS, accounts, form handling, Node tooling or build step.
- Layout/style modelled on https://tekt.com.au/ (clean, spacious, photo-led, card grids, simple top nav); never copy its text or images.
- Pages: Home (`index.html`), `results/`, `schedule/`, `sponsors/`, `team/`, `contact/` (each an `index.html`).
- Contact is email and social links only, no form.
- Data in `data/results.json`, `data/schedule.json`, `data/sponsors.json`; assets in `assets/css/`, `assets/js/`, `assets/logos/`, `assets/photos/`.
- Header/footer duplicated per page.
- Custom domain via `CNAME` in repo root; GitHub Pages deploys from `main`, root folder.
- Mobile-responsive. Placeholder content until real data/photos arrive; team name displayed as "Pondigas Motorsport" until owner confirms.
- All asset/link paths are root-relative-safe for a custom domain (use `/...` absolute paths).

## Review Focus

- Empty data file (no results / no upcoming races): page shows a friendly "No results yet" / "No upcoming races" message, not a blank area or JS error.
- Data file fails to load (typo, 404): page shows a short error message and the rest of the page still renders.
- Race with missing optional fields (no photo, no position, no link): renders without "undefined".
- Dates: schedule splits upcoming vs past using the visitor's local date; a race today counts as upcoming.
- Sponsor with missing logo file: card falls back to the sponsor name as text.

## File Structure

- `index.html`, `results/index.html`, `schedule/index.html`, `sponsors/index.html`, `team/index.html`, `contact/index.html`: pages.
- `assets/css/style.css`: all styling.
- `assets/js/render.js`: pure render functions (data to HTML strings), no DOM access.
- `assets/js/main.js`: loads JSON, calls render functions, injects into `[data-render]` elements.
- `data/*.json`: content.
- `scripts/check.py`: validates data and local links.
- `CNAME`, `.nojekyll`, `README.md`: deployment and update instructions.
